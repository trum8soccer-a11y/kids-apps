✏️ アプリの追加・URLの変更方法

この index.html をメモ帳やエディタで開き、スクリプト内の const APPS = [ ... ]; の部分を書き換えるだけで、カードの追加やリンク先の変更ができます。

  • url：各アプリのパス（例：'./bingo/index.html'）を指定します。
  • comingSoon：true にすると「じゅんびちゅう」バッジが付き、タップ時に案内メッセージが出ます。公開時は false にしてください。
  • tags：'outdoor'（おそと）や 'indoor'（おうち）を設定すると上のボタンで絞り込めます。
