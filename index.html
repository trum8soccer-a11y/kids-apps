⚙️ アプリの ふやしかた・リンクの かえかた

GitHub Pages では、この index.html と同じ階層に各アプリのフォルダを置くだけで公開できます。

📁 kids-apps/（リポジトリのトップ）
 ├── 📄 index.html（このメニュー画面）
 ├── 📄 manifest.json（アプリ化設定）
 ├── 🖼️ icon.png（ホーム画面アイコン）
 ├── 📁 bingo/      → index.html
 ├── 📁 photohunt/  → index.html
 ├── 📁 odaigame/   → index.html
 └── 📁 oekaki/     → index.html

リンク先やタイトルを変えるときは、このファイルの APPS の中身を書き換えてください。
